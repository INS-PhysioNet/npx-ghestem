## Protocol for Long-term near-continuous recording with Neuropixels probes in healthy and epileptic rats

In this repository you will find the 3D printing models to print the implants described in 

[Ghestem et al.; J Neural Eng. 2023 Jul 7;20(4); doi: 10.1088/1741-2552/ace218 ](https://iopscience.iop.org/article/10.1088/1741-2552/ace218)

As well as the scripts to seizures in LFP recordings as performed in the paper. 

All the details of the protocol are described in the manuscript.
